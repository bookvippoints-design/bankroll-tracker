# Control Bankroll 007 Picks

Webapp simple para controlar:
- apuestas simples
- apuestas sistema
- combinadas
- bank inicial de $5
- ganancia/pérdida
- ROI
- record de aciertos

## Archivos
- index.html
- supabase_schema.sql

## Cómo conectar con Supabase

1. Entra a https://supabase.com
2. Crea un proyecto nuevo.
3. Ve a SQL Editor.
4. Pega todo el contenido de `supabase_schema.sql`.
5. Ejecuta el SQL.
6. Ve a Project Settings > API.
7. Copia:
   - Project URL
   - anon public key
8. Abre `index.html`.
9. Reemplaza:
   - PEGA_AQUI_TU_SUPABASE_URL
   - PEGA_AQUI_TU_SUPABASE_ANON_KEY
10. Sube `index.html` a Netlify.
